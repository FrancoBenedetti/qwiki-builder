# Preventive Maintenance & Inspection Schedule

Adhering to strict preventive service routines maximizes equipment availability and extends operational lifespan.

## Service Frequency Matrix

| Interval | Task | Lubricant / Spec | Responsible |
| :--- | :--- | :--- | :--- |
| **Daily** | Visual inspection, clear debris, check oil sight-glass | N/A | Operator |
| **Weekly** | Grease pivot bearings (2 shots per point) | NLGI Grade 2 EP Grease | Maintenance Tech |
| **Monthly** | Inspect drive belt tension, test E-Stop circuit | Tension gauge: 350 N | Maintenance Tech |
| **Semi-Annual** | Oil drain and refill in main speed reducer | ISO VG 220 Gear Oil | Certified Tech |
| **Annual** | Electrical cabinet thermal imaging & terminal torquing | Torqued to spec table | Certified Electrician |

## Troubleshooting Common Fault Codes

| Fault Code | Description | Corrective Action |
| :--- | :--- | :--- |
| `E-101` | Emergency Stop Circuit Open | Inspect all E-Stop buttons and cable switches |
| `E-204` | Motor Overload Trip | Check process chamber for jamming; reset thermal relay |
| `E-312` | Low Lubrication Pressure | Inspect pump, reservoir level, and hydraulic filters |
