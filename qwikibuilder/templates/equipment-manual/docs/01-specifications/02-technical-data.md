# Technical Data & Environmental Specifications

Review all electrical, mechanical, and ambient criteria prior to site preparation.

## Electrical Specifications

| Parameter | Value | Tolerance |
| :--- | :--- | :--- |
| **Supply Voltage** | 400 VAC, 3-Phase + PE | ± 10% |
| **Frequency** | 50 / 60 Hz | ± 2% |
| **Full Load Amps (FLA)** | 32 A | Maximum |
| **Control Voltage** | 24 VDC (SELV) | Regulated |
| **IP Rating** | IP54 Enclosure / IP65 HMI | IEC 60529 |

## Ambient & Operating Conditions

- **Operating Temperature**: +5°C to +40°C (+41°F to +104°F)
- **Storage Temperature**: -20°C to +60°C (-4°F to +140°F)
- **Relative Humidity**: 10% to 90% non-condensing
- **Maximum Elevation**: 1,000 meters above sea level (derate motor above 1,000 m)
