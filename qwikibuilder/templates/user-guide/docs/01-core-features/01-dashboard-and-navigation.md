# Dashboard Navigation & Controls

The main dashboard provides real-time visibility into active operational queues, pending approvals, and document repositories.

## Layout Overview

- **Top Navigation Bar**: Global search, profile settings, and quick actions.
- **Sidebar Menu**: Hierarchical tree of categories and workspaces.
- **Main Viewport**: Operational forms, data tables, and rich document viewers.

## Keyboard Shortcuts

| Shortcut | Action |
| :--- | :--- |
| `/` or `Ctrl+K` | Focus global search |
| `Esc` | Close active dialog / modal |
| `Ctrl+P` | Print clean version of current page |
